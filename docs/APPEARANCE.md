# Оформление сайта

На административном домене откройте **Оформление**.

1. Выберите палитру: Nord, Dracula, Catppuccin Mocha / Latte, Gruvbox Dark / Light,
   Rosé Pine Dawn или Tokyo Night. «Оригинальная» сохраняет прежнее автоматическое
   переключение по теме устройства. Остальные палитры фиксированы для всех посетителей.
2. Кнопка **❄ Новогодняя тема** выбирает Nord, умеренный снег и гирлянду с мягким
   мерцанием. Каждый эффект можно включать отдельно и сочетать с любой палитрой.
3. Проверьте предпросмотр и нажмите **Сохранить оформление**. До сохранения
   предпросмотр не меняет публичный сайт. После сохранения обновите его страницу.

**Отменить изменения** возвращает последний сохранённый вариант.
**Вернуть оригинальную тему** выбирает исходную палитру и отключает украшения;
для применения тоже нужно сохранить.

Палитры распространяются вместе с приложением: браузер и сервер не обращаются к
TerminalColors при открытии страниц. Значения фона, текста и 16 ANSI-цветов взяты
из готовых Ghostty-ресурсов каталога. Ссылки на страницы и исходные ресурсы каждой
палитры сохранены в `src/lib/theme-palettes.json`; авторство палитр принадлежит их
создателям. `src/lib/appearance.ts` преобразует их в семантические CSS-переменные
существующей стеклянной темы. Произвольный CSS и цвета из запросов не принимаются.

Единый JSON в настройке SQLite `appearance` хранит палитру, `snow`, `garland`,
`snowDensity` (`light`, `medium`, `heavy`) и `twinkle`. Миграция БД не требуется,
настройка автоматически входит в существующие бэкапы. В старой БД или при
некорректной настройке используется исходное оформление с выключенными эффектами.
`GET /admin/api/appearance` читает настройки, `POST` целиком сохраняет проверенную
конфигурацию. Оба маршрута используют существующую защиту админ-домена и Basic Auth;
запись также проходит проверку Origin в middleware.

Украшения отрисовываются на сервере и анимируются CSS без гидратации и внешних
библиотек. Слой снега не перехватывает нажатия. На небольших экранах количество
видимых снежинок ограничено 24. `prefers-reduced-motion: reduce` отключает снег и
мерцание, оставляя статичную гирлянду. При печати украшения скрываются.
На самой админке остаётся исходная тема без украшений, изменения видны в её
предпросмотре и на публичном сайте, включая `/en` и страницы ошибок.

Для выкладки обновлённого кода используется обычная пересборка приложения по
[DEPLOY.md](DEPLOY.md). Включать оформление на сервере затем можно через админку
без новой сборки.
